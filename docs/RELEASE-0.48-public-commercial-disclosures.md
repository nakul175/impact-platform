# Release 0.48 coding candidate: public commercial disclosures

This coding candidate implements US-DC-04 / APL-370 as a separately addressable public disclosure directory. It publishes each current solution's stable ID, name, provider and complete commercial disclosure: known-relationship status, relationship types, explanatory statement, declaration date and editorial confirmation state.

The directory is produced only through the existing validated catalogue. If one listing lacks a disclosure label, has inconsistent relationship types, an invalid date, unsupported confirmation state or any other catalogue-contract breach, the complete directory is refused. It never silently supplies a default label.

`NONE_KNOWN` means no relationship is currently known under the stated pending editorial declaration; it is not proof that no relationship exists. `PENDING` remains visible and is not promoted to confirmed. The directory does not certify neutrality, endorse a provider or approve procurement.

Existing tenant catalogue, shortlist and comparison screens retain their accessible disclosure labels. Frozen historical guidance editions remain unchanged and continue to present their captured wording through their retained readers.

Status: coding complete as a candidate. Tests, CI, independent review, merge, deployment and owner acceptance have not been run or claimed, following the owner's request to batch those gates later.
