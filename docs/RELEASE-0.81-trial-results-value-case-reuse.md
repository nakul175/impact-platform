# Release 0.81 coding candidate — trial results feed the value case

US-AS-03 / APL-358 adds one immutable result for a completed advisor-led trial. The result remains bound to the trial's server-owned opportunity and may pin one exact governed Evidence revision. A dedicated value-case command selects the result by trial and supplies the recorded trial source automatically; callers submit baseline, cost and assumptions but cannot re-enter or replace the trial source or opportunity. The saved value-case revision retains the exact trial/result/opportunity pointer.

This candidate does not infer impact, causal benefit, provider output or acceptance. Existing self-reported value-case disclaimers and deterministic arithmetic remain. It has source checks only; tests, CI, merge, staging and acceptance are deferred.
