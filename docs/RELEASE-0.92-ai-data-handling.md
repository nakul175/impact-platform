# 0.92 AI model data handling

FR-AI-012 / APL-341 evaluates the exact purpose, data class, destination, region, provider retention mode and minimisation profile before an advisory reservation or provider call. The immutable reservation revision records the approved destination version and non-content handling decision.

The provider receives a minimized profile: exact team size becomes its existing capacity band, and email, phone and credential-shaped strings in the goal are redacted. Its assessment is recomputed from that minimized copy. Provider storage remains disabled, training reuse is explicitly false, evaluation-dataset eligibility is false, and the destination catalogue has no fallback. A provider outage therefore leaves the deterministic manual assessment and catalogue usable without sending content elsewhere.

This is a coding-only candidate. Source formatting, compilation and contract generation are not qualification. Tests, CI, independent review, merge, staging deployment and owner acceptance remain pending.
