# Release 1.25 coding candidate — governed dashboard publication

FR-ANA-008 / APL-614 adds an authority-checked recipient sharing preview that reports unavailable bindings without creating grants. Private copy remains a new draft and preserves no additional access.

Internal publication pins the exact dashboard revision, layout, bindings, audience, creator and expiry. Anonymous `PUBLIC` publication is refused in full because the product has no independently reviewed dashboard-disclosure artifact or safe retrieval boundary. The status read rechecks every pinned source revision and classification and reports `SUSPENDED` after expiry or a source authority/sensitivity change, but it does not persist that suspension. Publish retries use the exact operation identity and payload fingerprint.

The 16 October 2026 implementation audit confirms that APL-614 is **not coding-complete**. Still missing are cross-workspace funder copying; approved public disclosure artifacts and publication content retrieval; governed owner transfer; durable suspension plus an authorised revalidation/resume command; and a complete story-level qualification pack. Existing same-tenant private copy, sharing preview, internal manifest creation and computed status are bounded components only. This release adds no migration or privilege change and does not claim a positive-journey pass, CI, merge, staging deployment or acceptance for the complete story.
