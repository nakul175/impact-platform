# Nonprofit AI Enablement Test Scenarios and Cases

Edition 1.0   5 October 2026   Proposed test specification

This catalogue defines 50 scenarios and 108 cases covering all 40 FR-NPA requirements. Cases are executable specifications rather than newly executed results. Every case has status SPECIFIED_NOT_RUN. Named previous local assertions are related evidence, with a separate evidence status, and never turn a new case, whole requirement or target feature into an accepted result.

## How to execute and record a case

Read 05-TEST-STRATEGY.md before execution. Choose the exact candidate and layer harness, satisfy stated prerequisites and decision dependencies, provision only synthetic fixtures, then execute the steps and inspect the stated assertions. Record actual result, run identifier, candidate SHA, build/schema, environment and evidence path in a separate execution record. Mark a target or unapproved provider/hosting case BLOCKED with the exact reason; do not report it as passed or skipped to make a release green. Semicolons delimit multiple references in the CSV files.

The prose case entries below and test-cases.csv describe the same cases. test-scenarios.csv is the scenario inventory. Mutable execution outcomes belong in a separately versioned test run record; these design files remain the proposed baseline.
