## FSD and LLD supplement

For guided practice, read the current task-template response, resolve exactly one selected template and show its invented brief before mutation. Reject unavailable, ambiguous or oversized source content rather than truncate it. Bind the preview to the current parent context and worksheet fingerprint. With explicit current management and an unlocked action, replace the brief only and reset checks. Subsequent save uses the existing immutable plan command and its exact retry rules. Preview, cancellation, lesson reading and navigation never save or auto-complete progress.

For saved review, the parent captures the marker/snapshot only from successful current-authorised canonical GET on Open, or an eligible clean canonical reread after an existing evidence action. A save receipt updates its ordinary save state but clears canonical review until deliberate reopening. Render-time checks hide review immediately on context/head/read/dirty/unavailable mismatch; effects also clear retained snapshot state. Parent read and draft generations refuse delayed replacement/capture after relevant transitions. Current object authority is enforced by the API, including when a client capability hint is cached positive. The checklist reads known public profile/shortlist/progress/procurement/planning/pilot fields and only navigates to existing sections.

For category coverage, use exactly the current entered category lines. No lines means NOT_RECORDED; any null unit amount means UNKNOWN_AMOUNT; otherwise AMOUNTS_RECORDED, including explicit zero. The calculator still receives only the existing currency, period and offers. Its result retains exact decimal strings, unknown totals and tie semantics. The request signature includes the source context/revision locally; epoch and abort checks refuse delayed responses, and a mismatching signature hides results before effects run. There is no new server calculation or official-impact rule.

The public request adapter accepts only exact GET paths for bundled public catalogue and task-template data. Body, custom headers, credential options, mutation method and every other path are refused without invoking fetch. The separate static entry imports public components directly, avoiding the authenticated Workspace and private panels. Normal-app handlers, labels, current authority and save behaviour remain in the normal parent.
